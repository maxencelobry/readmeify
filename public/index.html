Use my own Spotify app (advanced)

A Spotify app in Development Mode can only serve 25 users until Spotify grants Extended Quota. If the shared app is full, register your own — it takes two minutes and lifts the cap for you.

  1. Open developer.spotify.com/dashboard and click Create app.
  2. Give it any name and description. Tick the Web API checkbox.
  3. Paste the Redirect URI below into Redirect URIs, click Add, then Save.
  4. Open the app, go to Settings, and copy the Client ID and the client secret.
  5. Paste both here, save, then connect Spotify again above.

Must match character for character, including the scheme and the port.

Dashboard → your app → Settings → Client ID. 32 characters, digits and a–f only.

Same page, under View client secret. It is encrypted with AES-256-GCM before it touches the database and is never sent back to the browser.
